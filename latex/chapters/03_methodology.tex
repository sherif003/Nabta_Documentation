\section{Overview}
\label{sec:methodology_overview}

This chapter presents the methodology adopted for designing, developing, and integrating the intelligent components of the proposed NABTA platform. The system was developed as a complete AI-powered smart agriculture platform that combines Computer Vision, Machine Learning, Explainable Artificial Intelligence, and Large Language Models within a unified web-based architecture.

Unlike conventional plant disease diagnosis systems that rely solely on image classification, NABTA adopts a multi-stage processing pipeline consisting of object detection, semantic segmentation, disease classification, explainable artificial intelligence, crop recommendation, irrigation recommendation, and retrieval-augmented conversational assistance. Each module was independently designed, trained, evaluated, and finally integrated through a FastAPI backend to provide a seamless end-to-end intelligent decision-support platform.

%==============================================================================
\section{System Architecture}
\label{sec:system_architecture}

The NABTA platform follows a modular service-oriented architecture consisting of five major layers.

\begin{enumerate}[leftmargin=*,label=\textbf{Layer \arabic*.}]

\item \textbf{Presentation Layer}

Developed using React.js, this layer provides all graphical interfaces including disease diagnosis, crop recommendation, irrigation recommendation, analytics dashboards, authentication, historical records, subscriptions, and AI consultation.

\item \textbf{Application Layer}

Implemented using FastAPI, this layer exposes RESTful APIs that coordinate requests between users and the deployed artificial intelligence models while handling authentication, validation, and response generation.

\item \textbf{Artificial Intelligence Layer}

The AI layer integrates all intelligent modules developed throughout this project:

\begin{itemize}[leftmargin=*]
\item YOLOv8x object detection
\item U-Net semantic segmentation
\item CNN disease classification
\item Grad-CAM explainability
\item Random Forest crop recommendation
\item Random Forest irrigation decision model
\item Random Forest water requirement regression model
\item Cohere Retrieval-Augmented Generation chatbot
\end{itemize}

\item \textbf{Cloud Services Layer}

Firebase Authentication manages user accounts, while Firebase Cloud Functions provide scheduled services, API key protection, backend automation, and notification services.

\item \textbf{Data Layer}

The data layer stores user accounts, disease analysis history, chatbot conversations, generated PDF reports, agricultural knowledge resources, and AI model outputs.

\end{enumerate}

The modular architecture allows every AI component to be independently trained, evaluated, updated, and deployed without affecting the remaining system components.

\section{Overall AI Pipeline}
\label{sec:overall_pipeline}

The proposed plant disease diagnosis framework consists of six sequential computer vision stages beginning with object detection and ending with disease severity estimation.

Figure~\ref{fig:overall_pipeline} illustrates the complete workflow adopted in the NABTA platform.

\begin{figure}[H]
\centering
\includegraphics[width=\textwidth]{assets/diagrams/end_to_end_plant_disease_pipeline.png}
\caption{Overall AI Pipeline of the Proposed NABTA Platform}
\label{fig:overall_pipeline}
\end{figure}

The complete disease diagnosis workflow proceeds as follows:

\begin{enumerate}[leftmargin=*,label=\textbf{Step \arabic*.}]

\item The uploaded plant image is analyzed using the YOLOv8x detector to localize infected leaf regions.

\item The detected leaf region is cropped from the original image.

\item The cropped image is passed to the U-Net segmentation model with an EfficientNet-B0 encoder to isolate the leaf from its surrounding background.

\item The segmented leaf is resized and forwarded to the proposed CNN classifier, which predicts one of 102 healthy or diseased plant classes.

\item Grad-CAM generates a visual explanation highlighting the regions that contributed most strongly to the prediction.

\item Disease severity is estimated using the segmented leaf together with the generated Grad-CAM activation map.

\end{enumerate}

Beyond disease diagnosis, the same platform integrates machine learning models for crop recommendation and irrigation recommendation, together with a Retrieval-Augmented Generation chatbot that provides evidence-based agricultural consultation.

\subsection{Object Detection Dataset}

The YOLOv8x detector was trained using an enhanced version of the PlantDoc dataset. Unlike laboratory datasets, PlantDoc contains images captured directly in agricultural fields under varying illumination conditions, cluttered backgrounds, partial occlusions, and multiple leaves within the same image.

To improve annotation quality, the original bounding boxes were manually reviewed and refined before training.

%==============================================================================
\subsection{Segmentation Dataset}

Semantic segmentation requires pixel-level annotations rather than image-level labels. Since publicly available segmentation datasets remain limited for plant disease applications, custom binary masks were generated specifically for this work.

Each mask identifies only the leaf pixels while excluding soil, stems, surrounding vegetation, and background objects, enabling accurate supervised training of the U-Net segmentation model.

\section{Data Preparation}
\label{sec:data_preparation}

Before training, all datasets underwent several preprocessing stages to improve data quality and ensure consistency across multiple data sources.

The preprocessing pipeline consisted of the following stages:

\begin{enumerate}[leftmargin=*,label=\textbf{P\arabic*.}]
\item Removal of corrupted or unreadable images.
\item Duplicate image removal.
\item Disease label standardization.
\item Class harmonization across datasets.
\item Image integrity verification.
\item Image resizing.
\item Dataset splitting into training, validation, and testing subsets.
\end{enumerate}

All classification images were resized to an input resolution of

\[
224 \times 224
\]

pixels before normalization into the range

\[
[0,1].
\]

Online data augmentation was applied during training to improve generalization and reduce overfitting. The augmentation strategy included random rotation, horizontal flipping, zooming, brightness adjustment, and minor geometric transformations.

\section{YOLOv8x Object Detection}
\label{sec:yolo_methodology}

Object detection represents the first stage of the proposed computer vision pipeline. Instead of directly classifying the entire image, the system first identifies the infected leaf region using YOLOv8x. This significantly reduces background noise and improves the subsequent segmentation and classification stages.

Among all YOLOv8 variants, the YOLOv8x model was selected because it provides the highest localization accuracy while maintaining practical inference speed suitable for deployment.

%==============================================================================
\subsection{YOLOv8x Architecture}

YOLOv8 is a one-stage object detector that simultaneously predicts object locations and class probabilities during a single forward pass through the network.

The architecture consists of three principal components:

\begin{itemize}[leftmargin=*]
\item Backbone for hierarchical feature extraction.
\item Neck based on Feature Pyramid Networks (FPN) and Path Aggregation Networks (PAN).
\item Detection Head responsible for predicting bounding boxes, confidence scores, and class probabilities.
\end{itemize}

\subsection{YOLOv8 Loss Function}

The optimization objective of YOLOv8 combines three complementary loss functions,

\[
L_{total}=L_{box}+L_{cls}+L_{dfl}
\]

where

\begin{itemize}[leftmargin=*]

\item $L_{box}$ minimizes the localization error of predicted bounding boxes.

\item $L_{cls}$ minimizes the object classification error.

\item $L_{dfl}$ represents Distribution Focal Loss, which improves bounding-box localization accuracy by modeling coordinate distributions.

\end{itemize}

Optimizing these three losses simultaneously enables the detector to accurately localize infected leaf regions under challenging field conditions.

%==============================================================================
\subsection{Detection Workflow}

The complete detection process consists of four sequential stages.

\begin{enumerate}[leftmargin=*,label=\textbf{D\arabic*.}]

\item Image preprocessing and resizing.

\item Feature extraction using the YOLOv8x backbone.

\item Prediction of candidate bounding boxes.

\item Non-Maximum Suppression (NMS) to remove duplicate detections.

\end{enumerate}

The final detected leaf region is forwarded directly to the segmentation stage.

\section{Leaf Segmentation using U-Net}
\label{sec:unet_methodology}

Although YOLO successfully localizes infected leaves, the detected region may still contain soil, stems, neighboring leaves, shadows, or other background objects. Such information may negatively affect disease classification.

To overcome this limitation, a semantic segmentation stage was introduced to isolate the leaf at the pixel level before classification.

The proposed segmentation module is based on the U-Net architecture with an EfficientNet-B0 encoder.

%==============================================================================
\subsection{U-Net Architecture}

U-Net is a fully convolutional neural network originally developed for biomedical image segmentation. Its encoder-decoder architecture enables accurate pixel-level segmentation while preserving fine spatial information through skip connections.

The encoder gradually extracts hierarchical visual features, whereas the decoder progressively reconstructs the segmentation mask at the original image resolution.

Skip connections transfer high-resolution spatial information from the encoder to the decoder, allowing the network to preserve fine object boundaries.

Figure~\ref{fig:unet_architecture} illustrates the adopted segmentation architecture.

\begin{figure}[H]
\centering
\includegraphics[width=\textwidth]{assets/diagrams/unet_efficientnetb0_architecture.png}
\caption{U-Net Architecture with EfficientNet-B0 Encoder}
\label{fig:unet_architecture}
\end{figure}

The EfficientNet-B0 encoder was selected because it provides an excellent balance between segmentation accuracy, computational efficiency, and model complexity.

%==============================================================================
\subsection{Segmentation Workflow}

The segmentation process consists of the following stages:

\begin{enumerate}[leftmargin=*,label=\textbf{S\arabic*.}]

\item Receive the cropped image from the YOLO detector.

\item Extract hierarchical visual features using EfficientNet-B0.

\item Decode feature maps through the U-Net decoder.

\item Generate a binary segmentation mask.

\item Remove the image background.

\item Produce a clean leaf image for disease classification.

\end{enumerate}

This preprocessing stage significantly reduces irrelevant visual information while preserving disease symptoms present on the leaf surface.

\section{Plant Disease Classification}
\label{sec:cnn_methodology}

Following leaf segmentation, the extracted leaf region is forwarded to a custom Convolutional Neural Network (CNN) responsible for disease recognition.

Unlike conventional image classifiers trained on a single dataset, the proposed CNN was developed using a unified dataset assembled from nine publicly available repositories. The diversity of plant species, disease categories, and imaging environments enables the model to generalize effectively to practical agricultural conditions.

The classifier predicts one of \textbf{102} healthy or diseased plant classes and produces a confidence score for every category.

%==============================================================================
\subsection{CNN Architecture}

Convolutional Neural Networks automatically learn hierarchical visual representations directly from image pixels through multiple convolutional layers.

Lower layers capture simple visual patterns such as edges and textures, whereas deeper layers progressively learn complex disease characteristics including lesions, discoloration, necrosis, and fungal infections.

The proposed CNN architecture was specifically designed for large-scale multi-class plant disease classification rather than relying entirely on existing transfer-learning architectures.

Figure~\ref{fig:cnn_architecture} illustrates the architecture adopted in this work.

\subsection{Classification Workflow}

The disease classification process consists of five sequential stages.

\begin{enumerate}[leftmargin=*,label=\textbf{C\arabic*.}]

\item Receive the segmented leaf produced by the U-Net model.

\item Resize the image to $224 \times 224$ pixels.

\item Extract hierarchical visual features through successive convolutional layers.

\item Generate probability scores for all disease classes using the Softmax layer.

\item Select the class with the highest prediction probability as the final diagnosis.

\end{enumerate}

The predicted disease together with its confidence score is subsequently forwarded to the explainability module.

\section{Explainable Artificial Intelligence using Grad-CAM}
\label{sec:gradcam_methodology}

Deep learning models often operate as black-box predictors, making it difficult for users to understand the reasoning behind their decisions.

To improve transparency and increase user trust, NABTA incorporates Gradient-weighted Class Activation Mapping (Grad-CAM), an explainable artificial intelligence technique that visualizes the image regions responsible for each prediction.

Instead of simply presenting a disease label, the system highlights the infected regions that contributed most strongly to the CNN decision.

%==============================================================================
\subsection{Grad-CAM Workflow}

The Grad-CAM algorithm follows the sequence below.

\begin{enumerate}[leftmargin=*,label=\textbf{G\arabic*.}]

\item Perform a forward pass through the CNN.

\item Extract feature maps from the final convolutional layers.

\item Compute the gradients with respect to the predicted class.

\item Apply global average pooling to obtain neuron importance weights.

\item Compute a weighted combination of feature maps.

\item Generate the final activation heatmap.

\item Overlay the heatmap onto the original leaf image.

\end{enumerate}

The resulting visualization clearly identifies the regions that influenced the prediction, allowing users to verify that the model focuses on biologically meaningful disease symptoms rather than irrelevant background information.

%==============================================================================
\subsection{Disease Severity Estimation}

Beyond visual explanation, Grad-CAM is also employed to estimate disease severity.

The activation heatmap is combined with the segmentation mask generated by the U-Net model. Pixels exhibiting high activation values are interpreted as infected tissue, while low-activation regions correspond to healthy leaf areas.

The proportion of infected pixels is then calculated to estimate disease severity, which is categorized into three levels:

\begin{itemize}[leftmargin=*]

\item Low

\item Moderate

\item Severe

\end{itemize}

This additional analysis transforms the CNN from a conventional image classifier into a practical decision-support system capable of providing more informative disease assessments for farmers and agricultural specialists.

\section{Crop Recommendation Model}
\label{sec:crop_methodology}

Beyond plant disease diagnosis, NABTA incorporates a machine learning-based crop recommendation system that assists farmers in selecting the most suitable crop according to soil characteristics and environmental conditions.

The recommendation model was implemented using a Random Forest classifier due to its robustness, high predictive accuracy, resistance to overfitting, and ability to model complex nonlinear relationships among agricultural variables.

The input feature vector consists of:

\begin{itemize}[leftmargin=*]
\item Nitrogen (N)
\item Phosphorus (P)
\item Potassium (K)
\item Soil Type
\item Soil pH
\item Temperature
\item Humidity
\item Rainfall
\end{itemize}

Prior to training, the agricultural dataset was regenerated using crop--soil suitability rules derived from agronomic knowledge. This process established realistic relationships between crop species and preferred soil types, improving the practical usefulness of the recommendation model.

The Random Forest classifier predicts the most suitable crop while providing probability scores for all candidate crops.

%==============================================================================
\subsection{Training Procedure}

The dataset was randomly divided into training and testing subsets while preserving class distributions.

Model performance was evaluated using:

\begin{itemize}[leftmargin=*]
\item Accuracy
\item Precision
\item Recall
\item F1-score
\item Five-fold Cross Validation
\end{itemize}

Random Forest was selected because it consistently achieved superior generalization performance compared with alternative machine learning algorithms evaluated during preliminary experiments.

\section{Smart Irrigation Recommendation}
\label{sec:irrigation_methodology}

Efficient irrigation management is essential for sustainable agriculture and water conservation. Therefore, NABTA incorporates two complementary machine learning models that support irrigation decision making.

The first model determines whether irrigation is currently required, whereas the second estimates the amount of water required under the current environmental conditions.

%==============================================================================
\subsection{Irrigation Decision Model}

The irrigation decision model was implemented using a Random Forest classifier.

The model receives environmental and soil measurements including soil moisture, temperature, humidity, rainfall, crop type, and soil type, then predicts whether irrigation should be performed.

The output consists of a binary decision:

\begin{itemize}[leftmargin=*]
\item Irrigation Required
\item Irrigation Not Required
\end{itemize}

%==============================================================================
\subsection{Water Requirement Estimation}

To estimate the amount of irrigation water required, a Random Forest regressor was developed.

The regression model predicts the expected crop water requirement measured in millimeters (mm), enabling farmers to optimize irrigation scheduling while reducing unnecessary water consumption.

Model performance was evaluated using:

\begin{itemize}[leftmargin=*]
\item Coefficient of Determination ($R^2$)
\item Mean Absolute Error (MAE)
\end{itemize}

The combination of the irrigation classifier and regression model enables both irrigation decision support and quantitative water requirement estimation.

\section{AI Agricultural Assistant}
\label{sec:rag_methodology}

To provide intelligent agricultural consultation beyond predictive analytics, NABTA integrates a conversational assistant based on Retrieval-Augmented Generation (RAG).

Unlike conventional chatbots that rely solely on large language models, the proposed assistant retrieves relevant agricultural knowledge before generating responses.

The consultation workflow consists of the following stages:

\begin{enumerate}[leftmargin=*,label=\textbf{R\arabic*.}]

\item Receive the user's agricultural question.

\item Retrieve relevant agricultural documents from the knowledge base.

\item Construct an augmented prompt combining the retrieved information with the user's query.

\item Generate the final response using the Cohere Large Language Model.

\item Return an evidence-based recommendation to the user.

\end{enumerate}

This retrieval mechanism reduces hallucinations while improving factual consistency and domain-specific response quality.

\section{System Integration}
\label{sec:system_integration}

All intelligent modules were integrated through a unified FastAPI backend exposing RESTful APIs.

The integration workflow follows these stages:

\begin{enumerate}[leftmargin=*,label=\textbf{I\arabic*.}]

\item User uploads a plant image through the React.js interface.

\item FastAPI forwards the image to the YOLOv8x detection service.

\item The detected leaf is segmented using U-Net.

\item The segmented image is classified using the CNN.

\item Grad-CAM generates the visual explanation and disease severity estimation.

\item Crop recommendation and irrigation services are executed whenever requested.

\item The RAG chatbot provides agricultural consultation.

\item Results are stored within Firebase and displayed through the analytics dashboard.

\end{enumerate}

The modular architecture allows each artificial intelligence component to operate independently while communicating through standardized RESTful interfaces.
